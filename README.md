# CS50 Simulador de Investimento

Este projeto consiste em uma aplicação web desenvolvida em Python que simula uma plataforma de investimentos, oferecendo uma experiência semelhante a um sistema real de compra e venda de ações.

## Funcionalidades
- Autenticação de Usuários
  - Registro de novos usuários
  - Login e logout
  - Controle de sessão
- Consulta de Ações
  - Busca de ações por símbolo
  - Exibição de preços atualizados via API
- Operações Financeiras
  - Compra de ações
  - Venda de ações
  - Validação de saldo disponível
   -Registro de transações
- Portfólio
  - Visualização das ações em posse
  - Histórico de transações
  - Atualização dinâmica dos valores
